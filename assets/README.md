## Demo GIF (`assets/demo.gif`)

`demo.gif` is currently a **scripted animation** (made with Hyperframes, converted from an mp4) of the README `/users` example — it is labeled as an illustration in the README. To replace it with a real recording, follow the spec below. Target ≤ 15 s, ≤ 3 MB, ~900 px wide, dark terminal,
large font.

**Scene 1 — normal Claude Code (≈6 s).** Prompt: `Why is my /users endpoint slow and how do I fix it?`
Let the long, polite answer scroll in (CAVEMAX off: `stop cavemax` / not installed).

**Scene 2 — CAVEMAX on (≈6 s).** Run `/cavemax max`, then the same prompt. The statusline shows `[CAVEMAX]`
and the reply is a few lines, with `/users`, `N+1`, `JOIN`, `FK` intact.

**Scene 3 — floor (optional, ≈3 s).** Ask something destructive (e.g. "delete node_modules recursively?") to show
the warning stays in full prose.

Tips: record with [VHS](https://github.com/charmbracelet/vhs), asciinema + agg, or ScreenToGif; use the real output of a
real run (it may differ from the README example); crop out secrets and your home path. Once saved, enable the image line in
the README's **Demo** section (it is currently an HTML comment).
